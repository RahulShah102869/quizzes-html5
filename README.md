# 🧠 Quizzes HTML5 – Interactive Quiz Website

An interactive and responsive quiz website built using HTML5, CSS3, and JavaScript to make learning more engaging and enjoyable.

🌐 **Live Demo:** [Play Quiz](https://quizzes-html5.netlify.app/)

---

## 🚀 About The Project

Quizzes HTML5 is a web-based quiz application designed to provide users with an interactive quiz experience. Users can test their knowledge, answer questions, and improve their learning through quizzes.

## ✨ Features

- 🧠 Interactive quiz experience
- ❓ Multiple-choice questions
- 📊 Score tracking
- 🎨 Clean and user-friendly interface
- 📱 Responsive website design
- ⚡ Fast and smooth performance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
